# Brainstorm to planning

## Goal

Capture ideas without treating old concept files as product specs.

## Workflow

1. Cluster items by system area; verify what exists in **code** before assuming features.
2. Put execution order in **`docs/milestones.md`** when the user wants tracking; append **`docs/dev-log.md`** for dated notes when useful.
3. Optional: point to **`docs/archive/2025-03-docs-consolidation/`** only for historical context.

## Guardrails

- Do not revive removed features based on brainstorms or archived docs alone.
